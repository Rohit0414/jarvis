Advanced Order Routing

Importing an order sounds simple until you account for international taxes, complex discount rules, and specific shipping methods. Our connector handles the financial integrity of your orders flawlessly.

  • ➡ Smart Customer Matching: Prevents duplicate customer creation by matching existing records via email before creating new contacts.
  • ➡ Shipping Lines: Automatically converts Magento shipping fees into dedicated product lines on Odoo sales orders.
  • ➡ Discount Adjustments: Captures cart-level and line-level Magento discounts, creating accurate negative adjustment lines in Odoo.
  • ➡ Import Date Controls: Never import historical orders by accident. Set a strict "Import from Date" threshold.

Multi-Source Inventory (MSI)

Magento 2's MSI (Multi-Source Inventory) system is powerful but complex to map to ERPs. We have engineered a direct translation layer between Odoo Warehouses and Magento Sources.

  • ➡ Warehouse Mapping: Link specific Odoo warehouses to specific Magento source codes. You can sync multiple warehouses independently.
  • ➡ Safety Stock Protection: Define a global safety stock threshold in Odoo. If Odoo has 5 items but safety stock is 5, we send 0 to Magento to prevent overselling.
  • ➡ Flexible Quantity Fields: Choose exactly which Odoo stock field (e.g., 'Free to Use', 'On Hand') calculates your exportable inventory.

Frequently Asked Questions

Does this connector overwrite Odoo product data?

By default, the connector treats Magento as the source for the initial import, but relies on Odoo for ongoing inventory management. Product names and SKUs are imported initially, but subsequent order syncs will not overwrite descriptions you have refined inside Odoo.

How does it handle Magento Configurable Products?

The connector primarily binds on the Simple Product level (the actual variant with a unique SKU and physical stock). When an order is placed for a configurable product in Magento, the connector identifies the specific simple product SKU purchased and allocates inventory accordingly in Odoo.

Do I need to install anything on my Magento server?

No. Our connector uses Magento 2's native REST API. You only need to create a new Integration via your Magento Admin Panel, generate an Access Token, and ensure your server firewalls allow incoming API requests from your Odoo server's IP address.

What happens if the Magento API goes down?

Odoo safely catches the timeout. The job is placed into the "Failed Jobs" queue. Once Magento is back online, you can simply click "Retry All Failed Jobs" from the Odoo dashboard to process the backlog without losing any data.
