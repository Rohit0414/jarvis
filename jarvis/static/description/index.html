The Design Philosophy

Integration should be visible, not a black box.

Most ERP connectors operate entirely in the background. While this sounds convenient, it becomes an operational nightmare when something goes wrong. If a customer uses a strange character in their address, or an old SKU is deleted in Magento, standard connectors simply drop the order without warning.

We designed Magento 2 Connector Pro with absolute operational transparency. Every sync action has a dedicated button. Every API call has a log. Before you run a massive catalog import, our built-in Readiness Checker validates your connection, warehouse mappings, and configuration to ensure zero data corruption.

Technical FAQs

Everything you need to know about how the module handles your data.

Does it support Configurable Products?

Yes. The connector imports configurable products but smartly focuses inventory and order binding on the underlying "Simple Product" variant (the item with the actual physical stock and unique SKU).

Will it overwrite my Odoo descriptions?

No. Product data is mapped during the initial import. Ongoing daily order syncs or inventory pushes do not wipe out internal descriptions or metadata you've added to Odoo.

What happens if the API drops?

The job queue catches timeouts. Failed actions are neatly stored in the "Failed Jobs" menu with the exact error. Once connectivity is restored, click "Retry All" to process the queue without data loss.

Do I install a Magento extension?

No plugin installation is required on your Magento server. The entire integration runs utilizing standard Magento 2 REST API endpoints via a generated access token.
