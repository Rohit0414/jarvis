Configuration Guide

Step 1: Azure Portal Setup

1.1 App Registration

Register Odoo as a "Service Principal" in Azure Active Directory (Microsoft Entra ID) to generate your credentials.

  • Create a New Registration named "Odoo Synapse Connector".
  • Generate a Client Secret (Copy the value, not the ID!).
  • Grant API Permissions: Azure SQL Database > user_impersonation.
💡
Finding your Synapse Endpoint

In your Synapse Workspace overview, find the "Dedicated SQL Endpoint". It usually looks like: yourworkspace.sql.azuresynapse.net

Odoo Interface

Step 2: Connect Odoo to Synapse

Enter Credentials

Input your Tenant ID, Client ID, and Secret into the Synapse Settings menu.

Test Connection

Use the "Test Connection" button to verify Odoo can reach your Dedicated SQL Pool.

Database Whitelisting

Ensure your Odoo Server IP is allowed in the Azure Synapse Firewall settings.

The "CDC" Advantage

Our Change Data Capture logic tracks the write_date in Odoo. If you have 1 million records but only 500 were updated today, only those 500 are pushed to Azure.

Troubleshooting Guide

❌ Error: Login Failed for user (Service Principal)

Fix: You must add your Service Principal as a user inside the Synapse SQL Pool using T-SQL: CREATE USER [App_Name] FROM EXTERNAL PROVIDER;

❌ Error: Connection Timeout

Fix: Verify your Odoo server IP is added to the "Networking" firewall settings of the Azure Synapse workspace.

❌ Error: Batch Limit Exceeded

Fix: If exporting massive models (Account Move Lines), reduce the "Batch Size" in Odoo settings to 5,000 or 10,000.

Frequently Asked Questions

Does it support Serverless SQL Pools?

Currently, the module is optimized for Dedicated SQL Pools to ensure maximum performance and schema stability.

Will it slow down my Odoo?

No. We use cursor-based batching and incremental sync to ensure minimal impact on Odoo's performance.
