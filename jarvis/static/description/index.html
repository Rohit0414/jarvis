Technical FAQ

Everything you need to know

✶ Does this work only with ChatGPT?

No. It is built for MCP clients in general, including ChatGPT, Claude, Cursor, Codex, VS Code, and other tools that can connect to MCP servers.

✶ Can it connect with Cursor?

Yes. The module provides Cursor-ready remote MCP configuration and a local STDIO bridge option for development or localhost Odoo instances.

✶ Do users need to know Odoo model names?

No. Access bundles are designed around business apps such as Sales, CRM, Inventory, Purchase, Accounting, Project, and Helpdesk.

✶ What keeps AI from accessing everything?

The execution user, assigned bundles, Odoo ACLs, record rules, forced domains, field filters, permission presets, and audit logging control what clients can access.

✶ Can admins fine-tune access?

Yes. App-based bundles handle the main setup, and admins can manually include or exclude models when a customer workflow needs tighter control.

✶ Is there setup troubleshooting?

Yes. The diagnostics endpoint helps identify missing tokens, disabled MCP status, incorrect execution user, zero exposed models, and client configuration issues.
