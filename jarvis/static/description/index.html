Step 01: Configure

Add your BigQuery Project ID, Dataset ID and service account JSON from Odoo Settings. Your team controls the Google Cloud destination, dataset and credentials.

For each export, choose the Odoo source table, select only needed columns, add a domain filter, and decide whether it runs manually or on an incremental schedule.

FAQ

Questions buyers ask before purchase.

Does this replace Power BI, Looker or Tableau?

No. It feeds BigQuery with Odoo data so those tools can read from a proper analytics warehouse.

Can I export only specific records?

Yes. Use Odoo domain filters to restrict records, for example posted invoices, confirmed sales orders, active products or company-specific data.

Can I choose only required fields?

Yes. The query form lets you select columns instead of exporting every field by default.

Does it support incremental sync?

Yes. You can enable incremental auto export per query and set the sync interval. The connector manages related Odoo cron records.

What happens if an export fails?

Admins can inspect the error, clear it, review logs, and reset stuck export state when a previous run was interrupted.

What do I need before setup?

You need a Google Cloud project, a BigQuery dataset and a service account JSON with the required BigQuery permissions.
