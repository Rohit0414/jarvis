ARCHITECTURE

How Niyu AI Works (Under the Hood)

Natural language and uploaded files go through a governed reasoning flow. For Odoo questions, the module builds schema context, generates read-only SQL, verifies the result, and shows a table you can drill into using native Odoo pages.

📜

1) Understand Your Odoo Context

The engine reads governed models, fields, relations, labels, selection values and semantic terms so it understands both standard Odoo apps and your custom modules.

🧱

2) Reason with the Right AI Provider

Use OpenAI, Gemini, Claude or any OpenAI-compatible API. Strong reasoning models handle SQL planning, correction, summaries and file-based questions.

🔒

3) Verify, Table, Drill Down

Only safe read-only queries are executed. Results are shown as professional tables with verification notes, clickable native Odoo records, source lists, charts and exports.

Example: Using a Custom Map

See how a custom map ("shipments" → "stock.picking") turns a simple question into a powerful query:

YOUR QUESTION

"Show me all late shipments to Azure Interior"

GENERATED SQL
SELECT sp.name, sp.scheduled_date
FROM stock_picking sp
JOIN res_partner rp ON rp.id = sp.partner_id
WHERE rp.name = 'Azure Interior'
  AND sp.state NOT IN ('done', 'cancel')
  AND sp.scheduled_date < NOW();

SETUP IN MINUTES

Installation & Configuration

Install the module, choose your AI provider, add your API key, and start asking questions from live Odoo data or uploaded files.

  1. Get the module from the Odoo App Store.
  2. Install it by adding the module folder to your custom addons directory or deploying it through Odoo.sh.
  3. Choose your AI provider in Settings → Niyu AI Analyst.
  4. Add the matching API key for your selected provider:
    OpenAI Gemini Anthropic Claude OpenAI-compatible API
  5. Configure governed access by selecting which Odoo models the AI can use.
  6. Ask your first question, for example: “Show unpaid customer invoices grouped by customer”.
  7. Optional: upload a CSV, Excel, PDF, DOCX, TXT, JSON, XML, HTML, LOG, or SQL file from the question box and ask the AI to read or analyze it.
✓ Works with multi-company and respects the logged-in user’s Odoo access rights.
Compatibility & Requirements

Data Handling

FAQ

Frequently Asked Questions

What Odoo versions are supported?

This app store build is made for Odoo 19. The technical folder name is niyu_odoo_ai and the module follows Odoo 19 list views, security group privileges and client-action behavior.

How is my Odoo data kept secure?

For live Odoo questions, the module uses governed schema metadata and your question to generate safe read-only SQL. SQL runs in your Odoo database and the table result is shown inside Odoo. If you attach a file, the extracted file text is used for that question so the selected AI provider can summarize or analyze it.

Does it work on Odoo.sh and On-Prem?

Yes. Niyu AI Analyst runs on Odoo.sh and self-hosted / On-Prem environments.

What types of questions can Niyu AI answer?

Anything that can be answered from governed Odoo data: Sales, Invoices, AR, Inventory, Purchase, CRM, Projects, HR and custom apps. It handles filters, sorting, group-by, aggregations, dates and related models. It can also read uploaded CSV, Excel, PDF, DOCX, TXT, JSON, XML, HTML, LOG and SQL files for file-based questions.

Can I use it with custom modules and custom fields?

Yes. It reads governed custom models and custom fields. Admins can also use the Semantic Dictionary so business terms like “shipment”, “case”, “property” or “hotel” point to the right Odoo models and fields.

Can I see or copy the SQL?

Yes. SQL transparency is a core feature-you can view and copy the exact SQL produced for any answer.

Is it read-only? Can it change my data?

Niyu AI Analyst is designed for read-only analysis. The generated SQL is intended to retrieve data, not modify it.

What are the technical requirements?

  • Odoo 12+ up to your current version
  • Outbound internet from the Odoo server to the OpenAI API
  • Your selected AI provider API key (kept in your Odoo settings)
  • No special server changes beyond standard Odoo hosting.

How fast is it?

Typical answers arrive in seconds. Final latency depends on your DB size, indexes, and question complexity. Long-running queries behave like any report/query on your DB.

What export options are available?

You can export results to PDF and CSV for sharing, reviews, and meetings.
