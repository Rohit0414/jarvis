FAQ

Questions buyers ask before purchase.

Does this replace Power BI, Looker or Tableau?

No. It feeds BigQuery with Odoo data so those tools can report from a proper analytics warehouse.

Can I export only specific records?

Yes. Use Odoo domain filters to restrict records such as posted invoices, confirmed sales orders or company-specific data.

Can I choose only required fields?

Yes. The query form lets you select columns instead of exporting every field by default.

Does it support incremental sync?

Yes. Enable incremental auto export per query and set the sync interval. The connector manages the related Odoo cron records.

What happens if an export fails?

Admins can inspect the error, clear it, review logs and reset stuck export state when a previous run was interrupted.

What do I need before setup?

You need a Google Cloud project, a BigQuery dataset and a service account JSON with the required BigQuery permissions.
