Query Your Data

Once the sync runs, your Odoo models appear as standard SQL tables in Synapse Studio.

-- Example: Calculate Total Sales by Partner
SELECT p.name AS partner_name,
SUM(s.amount_total) AS total_revenue
FROM dbo.sale_order s
JOIN dbo.res_partner p ON s.partner_id = p.id
WHERE s.state = 'sale'
GROUP BY p.name;

Troubleshooting

Connection Failed?
  • Check if your SQL Pool is Paused in Azure Portal.
  • Verify the Odoo Server IP is whitelisted in Synapse Networking.
  • Ensure SAS Token includes "Write" and "Create" permissions.
Data Mismatch?
  • Check the Export Profile domain filters in Odoo.
  • Ensure no other process is locking the tables in Synapse.
