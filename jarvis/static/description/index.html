STEP ONE

Find your Synapse Codes

First, we need to know the name of your Azure computer and the SQL pool.

1. Log in: Go to portal.azure.com.

2. Search: Type "Synapse" in the top bar. Click on Synapse workspaces.

3. Click Workspace: Choose your workspace from the list.

4. Copy Endpoint: Under the "Overview" tab, find Workspace SQL endpoint. It ends in .sql.azuresynapse.net. Save this!

5. Find Pool: On the left menu, click SQL pools. Copy the name of your Dedicated pool (example: odoo_dedicated).

STEP TWO

The Magic Storage Box

Odoo needs a place to drop off files. We call this the ADLS Gen2 Storage Account.

1. Search Storage: Type "Storage" in the Azure search bar. Click Storage accounts.

2. Copy Name: Copy the name of your storage account exactly (example: niyuadlscentral).

3. Create Container: Click Containers on the left menu. Click the + Container button at the top.

4. Name it: Type "synapse" as the name and click Create.

⚠ Very Important: Make sure your Storage Account has "Hierarchical Namespace" turned ON in the configuration!

📷 Click "+ Container" and enter "synapse" as the name

STEP THREE

Make the Secret Key (SAS Token)

This key allows Odoo to open the Magic Box and put files inside.

The "Click Checklist":

➀ In your Storage Account, click Shared access signature on the left.

➁ Check Service, Container, and Object.

➂ Check Read, Write, List, Create, Delete.

➃ Change the "End Date" to next year so the key lasts a long time.

➄ Click the blue Generate SAS and connection string button.

⚠ What to copy:

After you click the button, 3 boxes will appear. You only need the one called SAS token.

sv=2022-11-02&ss=b&srt=co&sp=rwdlac...

Tip: If there is a "?" at the very beginning of the string, delete it when pasting into Odoo!

STEP FOUR

Open the Magic Door

Azure is very shy. If you don't tell it to talk to Odoo, it will keep the door locked.

1. Go back to Synapse: Open your Synapse Workspace page again.

2. Networking: Click on Networking on the left menu (under Security).

3. The Switch: Check the box that says "Allow Azure services and resources to access this workspace."

4. Your IP: Click + Add client IP at the top. This lets your current computer talk to Azure too.

5. Save: Don't forget to click the Save button!

📷 Important: Check "Allow Azure services" and click Save!

COMMON QUESTIONS

Stuck? Let's fix it!

❓ Why does "Test Connection" fail?

Most likely the **Firewall** (Step 4). Make sure you clicked "Allow Azure services" and also added your "Client IP". Also, double check that your SQL Pool is **started** and not paused.

❓ Does this work with Odoo Community?

Yes! Our connector works perfectly with Odoo Community, Enterprise, and Odoo.sh (Version 16, 17, and 18).

❓ What is "Hierarchical Namespace"?

It's a setting in your Storage Account that makes it act like a real folder system (ADLS Gen2). You must turn this **ON** during the creation of your storage account.

❓ My SAS Token expired! What do I do?

Simply repeat **Step 3**, generate a new token with a future date, and paste the new one into Odoo. The bridge will start working again instantly!

Click Run Now to send it! Turn on Auto-Sync and set it to 15 minutes so Odoo does it while you're playing.
