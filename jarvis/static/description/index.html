How It Works: Under The Hood

We have programmed complex logic to handle Magento's most notoriously difficult architectural quirks. Here is exactly what our module is doing for you.

📒

Catalog & Binding

When importing products, the module establishes unbreakable hashed bindings between Magento SKUs and Odoo Products.

  • ➜ Intelligent Auto-Create: Automatically creates missing Odoo products during import to ensure orders never fail.
  • ➜ Configurable Parent Handling: Safely processes both Simple and Configurable products, parsing `custom_attributes_json` to map Category structures accurately.
  • ➜ Metadata Protection: Protects your internal Odoo descriptions from being overwritten during daily syncs.
📦

Order Math Guardrails

Magento calculates taxes differently than Odoo. We built a robust Order Total Policy to handle discrepancies automatically.

  • ➜ Tolerance Policies: Set a financial threshold (e.g., $0.05). You can configure the module to Warn, Adjust, or completely Block orders that fail the math check.
  • ➜ Adjustment Lines: Automatically injects a service product line to reconcile rounding differences between the two systems.
  • ➜ Variant Splitting: The module actively ignores Magento `parent_item_id` rows, ensuring only the physical Simple Product variant is added to the Odoo Sale Order.
📊

MSI & Safety Stock

Fully supports Magento Multi-Source Inventory (MSI) via the `/V1/inventory/source-items` endpoint, or Classic Stock.

  • ➜ Multi-Warehouse Routing: Map specific Odoo warehouses to precise Magento Source Codes.
  • ➜ Safety Stock Protection: Define a deduction amount. If Odoo has 5 items but Safety Stock is 5, we send 0 to Magento to prevent overselling.
  • ➜ Quantity Control: Choose your exact calculation base (On Hand, Forecasted, or Free to Use).
⚙

Resilient Queue Engine

Operations shouldn't freeze during a network hiccup. Every sync action is packaged into a tracked, retriable background job.

  • ➜ Exponential Backoff: If Magento times out, the job automatically reschedules itself using `min(60, 2 ** max(0, retry_count - 1))` logic.
  • ➜ Collision Locks: Generates strict `external_key` hashes to prevent duplicate queue jobs from piling up.
  • ➜ Human Error Explanations: Captures raw Magento API JSON responses and translates them (e.g. "SKU not found" or "Token unauthorized") into actionable IT advice.
🚚

Automated Shipments

When your warehouse validates a delivery, the module securely bridges the gap back to Magento.

  • ➜ Delivery Hook: Replaces manual data entry by triggering an Export Shipment job when a stock.picking state becomes 'done'.
  • ➜ Tracking Sync: Captures Odoo carrier tracking references and pushes them directly to the Magento frontend to notify customers.
  • ➜ Item_ID Matching: We parse the `order_items_json` mapped during import to ensure Magento knows *exactly* which partial lines shipped.
🔍

Centralized Mapping

Avoid hardcoded messes. A beautiful user interface allows non-developers to link Magento logic to Odoo structures.

  • ➜ Comprehensive Types: Map Payment Methods, Shipping Methods, Tax Classes, Order Statuses, and Customer Groups cleanly.
  • ➜ Odoo Record Targeting: Map directly to specific Odoo Database IDs and Model names, eliminating text-matching errors.
  • ➜ State Management: Mark mappings as 'Unmapped', 'Mapped', or 'Ignored'. The Readiness checker will warn you if required items are ignored.

How to Use The Connector

We built a strict, guided workflow. You cannot corrupt your database if you follow the Readiness Wizard.

1

Configure Credentials

Enter your Magento Base URL and Admin Access Token. Click the Test Connection button to instantly verify SSL rules and token ACL permissions.

2

Import Architecture

Click Import Stores. This pulls Magento's deep hierarchy (Websites → Store Groups → Store Views) so Odoo understands exactly where orders originate.

3

Check Readiness Score

Click Check Readiness. The module will scan your database for duplicate SKUs, missing warehouse selections, and unmapped tax logic. Fix any "Blocking" errors.

4

Sync Catalog & Orders

Set an `Import From` date guardrail, then click Import Products followed by Import Orders. The Queue Engine will take over and process batches in the background.

5

Reconcile & Export Stock

Run the Inventory Drift check. Once you confirm quantities are calculated properly, click Export Stock to push Odoo inventory live to Magento.
