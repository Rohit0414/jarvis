What does this module do?

Enterprise-level data pipeline for the Microsoft Azure Cloud.

🏗

Automatic Schema Alignment

No need to manually create tables in Azure. The module detects Odoo fields and creates the corresponding T-SQL tables in your Dedicated SQL Pool automatically.

⚡

High-Speed Staging

Uses ADLS Gen2 (Azure Data Lake) as a high-speed staging area. This allows for bulk ingestion using the COPY INTO command, which is 10x faster than standard row-by-row inserts.

🔄

Change Data Capture (CDC)

The module tracks the Last Sync Watermark. It only pushes new or updated records (Incremental Sync), saving you bandwidth and Azure compute costs.

🛡

Secure SAS Authentication

Secure your data pipeline using Shared Access Signatures (SAS). Odoo never needs your full Azure Account Key, ensuring maximum security compliance.

Step 01: Azure Environment

Azure Portal Configuration

Required Values:
  • 💾 SQL Endpoint: Ends in .sql.azuresynapse.net
  • 🏢 Storage Account: Your ADLS Gen2 name
  • 🔑 SAS Token: Shared Access Signature for the container
  • 👤 SQL Admin: User with db_owner access
Where to find SQL Endpoint:

Azure Portal ➞ Synapse Workspace ➞ Overview ➞ Workspace SQL endpoint.

Generating the SAS Token:

Go to your Storage Account ➞ Containers ➞ Select your 'synapse' container ➞ Shared access tokens.

Required Permissions:

Read Write List Create

Note: Ensure the expiration date is set to at least 6-12 months.

Step 02: Odoo Settings

Connector Setup

Navigate to Settings ➞ Synapse Connector Pro

📷 Global Connection Profile

Testing the Connection:
  • Enter your Workspace URL and Dedicated Pool Name.
  • Input the ADLS Storage Name and the Container Name.
  • Paste your SAS Token (ensure it starts with sv=).
  • Click Test Connection.
Firewall Reminder:

You must whitelist your Odoo Server's IP address in the Azure Synapse Networking tab, or enable "Allow Azure services and resources to access this workspace."

Firewall Rule: Odoo_Server_Allow

Fixing Common Issues

Most errors are related to Azure Security or T-SQL permissions.

❌ Error: "Login failed for user..."

Fix: Ensure the SQL user has db_owner or db_datawriter permissions on the specific SQL Pool, not just the workspace.

❌ Error: "Cannot verify SAS token..."

Fix: Check if the Storage Account has Allow Trusted Microsoft Services enabled and the SAS token hasn't expired.

❌ Error: "Polybase/Copy Into failed"

Fix: Synapse Dedicated Pools require specific characters for table names. Avoid using spaces or special characters in the Synapse Table Name field in Odoo.

Frequently Asked Questions

Does it work with Serverless Pools?

Currently, the module is optimized for Dedicated SQL Pools to support full Change Data Capture (CDC) and indexed reporting.

Will it slow down my Odoo?

No. We use batch-based processing and ADLS Gen2 staging, meaning Odoo performance remains unaffected during sync.

Can I sync custom Odoo fields?

Yes. Any field added via Odoo Studio or custom code will appear in the Field Selection list.
