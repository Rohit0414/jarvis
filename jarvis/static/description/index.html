Under the hood

Built for large Odoo tables, not demo records.

The connector uses batching, schema handling, staging tables, MERGE logic, locks, cursors and recovery state.

📦

50,000 row batches

The export engine processes data in chunks to reduce long request risk and continue work through cron.
🔄

Cursor based export

The module tracks last sync timestamp and last synced ID for incremental continuation.
🔒

Lock protection

Export locks and stuck-state detection reduce duplicate or crashed run confusion.

🔗

Temporary staging

Each batch loads to a temporary BigQuery staging table before the final table update.
⇄

MERGE into target

BigQuery MERGE updates matched records and inserts missing records using the record key.
🛠

Type conversion

Values are transformed for BigQuery types such as string, integer, float, boolean, timestamp and date.
