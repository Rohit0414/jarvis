Practical Filters

Do not dump everything.
Export records that match the report.

Odoo domains let admins turn business rules into reporting filters before the data reaches Power BI.

Finance

Posted invoices only

Keep draft invoices out of revenue dashboards.

[('state','=','posted')]
Sales

Confirmed sales only

Keep quotations out of sales performance dashboards.

[('state','in',['sale','done'])]
Inventory

Active products only

Avoid archived products in inventory and purchase reports.

[('active','=',True)]

FAQ

Questions before you install.

Straight answers for Odoo admins, BI teams, and implementation partners.

Does it work with Power BI Service?

Yes. It works with Power BI Service so teams can use the cloud reporting experience.

Does it work with Power BI Desktop?

Yes. It works with Power BI Desktop for building reports, testing datasets, and using DirectQuery or Import mode.

Is a data gateway required?

No separate data gateway is required for this connector flow. Power BI connects to the prepared reporting source, and refresh is supported on Desktop and Service.

How fast can refresh be set?

The Odoo sync interval can be set as short as 1 minute. Actual report refresh behavior then depends on your Power BI connection mode and refresh setup.

Does it work with DirectQuery and Import mode?

Yes. It works with both DirectQuery and Import mode, so teams can choose the Power BI setup that fits their reporting need.

Do I need a paid Power BI account?

The connector itself does not require a paid Power BI account. Power BI licensing depends on how your team uses Microsoft features such as sharing, workspace publishing, and service governance.

How many users can connect to Power BI?

There is no connector-side user cap. Your Power BI access and sharing rules are controlled by your Microsoft setup.

Does it slow down Odoo?

No direct reporting load is placed on live Odoo screens. Odoo sends lightweight incremental data to the warehouse, and Power BI connects to that warehouse instead of querying Odoo directly.

Do I need SQL knowledge?

No. Queries are created from Odoo models, fields, and domain filters inside the Odoo interface.

Can I audit exports?

Yes. Query logs and change logs help review runs, configuration edits, and issues from inside Odoo.
