Multi-warehouse planning without the usual mess

In many businesses, stock is not the problem. Stock in the wrong place is the problem. One warehouse is short. Another one has extra. The team does not notice in time, so they buy again.

This module checks that.

Product Manual

Installation

Install the module like any normal Odoo module. It works with: Odoo Enterprise, Odoo Community, Odoo.sh, On-premise.

Setup

Go to the module settings and enter your API key. This key connects your Odoo instance to our forecasting and planning server. Then run the initial sync.

What each menu means

Planning Overview: Main control panel. Action Lines: Working queue. Planning Rules: Logic control. Exclusions: Clean up output.
