Setup

From installation to first synchronized workspace

A manager completes the OAuth connection once; users then work with normal Odoo project records and the Wrike menu.

1

Install the module

Install Wrike Connector for Odoo. The module adds the Wrike application, access groups, queue cron, records, and native Odoo integrations.

2

Create a connection

Open Wrike → Connections, create a connection, choose its Odoo company, and enter the Wrike OAuth Client ID and Client Secret.

3

Register the callback

Copy the generated OAuth Redirect URL from Odoo and add it to the callback URLs of the corresponding Wrike OAuth application.

4

Authorize and test

Click Connect to Wrike, approve access, then use Test Connection to verify the account identity and API host.

5

Choose sync behavior

Set the import date, auto-create policies, comment behavior, timesheet policy, automatic Odoo exports, and default Wrike export parent.

6

Import and enable events

Run Import Workspace. For event-driven updates, configure a public HTTPS web.base.url and create the signed webhook.

The webhook URL must be publicly reachable over HTTPS. Localhost and non-HTTPS endpoints are rejected by the connector before webhook creation.

Frequently asked questions

Important behavior before deployment

Does it automatically export every Odoo project?

No. A project must have a Wrike connection. New exports also require a configured default Wrike parent folder/project.

Will imported Wrike contacts create Odoo contacts?

Only when Auto-create Partners is enabled. Otherwise the connector links to an existing partner or user when the email matches.

Can Wrike timelogs become Odoo timesheets?

Yes, when automatic timesheet creation is enabled and the imported Wrike task is linked to an Odoo task. Employee mapping is used when available.

What happens when Wrike temporarily fails?

Recoverable failures such as timeouts, rate limits, conflicts, and server errors move to retry waiting. Non-recoverable configuration or authorization failures are blocked for review.

Does the connector export Wrike users or custom-field definitions?

No. Contacts/users and custom-field definitions are imported for matching and reference. Their creation in Wrike is intentionally not automated.

Can I run synchronization manually?

Yes. Managers can import individual areas, import the complete workspace, process the queue, retry jobs, or sync linked projects, tasks, and timesheets from their forms.
