Step 01: Azure Configuration

Find Workspace Endpoints

Open your Azure Portal and navigate to your Synapse Workspace.

Details to Capture:
  • · SQL Endpoint: Copy the "Workspace SQL endpoint" (ends in .sql.azuresynapse.net)
  • · SQL Pool Name: The exact name of your Dedicated Pool (e.g., SalesDW)
  • · SQL Auth: Use your SQL Admin username and password for initial setup.

📷 Azure Synapse Overview Screenshot

Step 02: ADLS Gen2 Storage

Secure Landing Zone

The "Secret Key" Checklist (SAS Token):

Azure Synapse requires an ADLS Gen2 storage account to process data transfers.

  • Go to Storage Account → Shared access signature.
  • Allowed services: Blob | Allowed resource types: Service, Container, Object.
  • Permissions: Read, Write, List, Create, Delete.
  • Generate SAS and copy the SAS Token string.

📷 Generating SAS Token in Azure Storage

Common Settings Reminder:
Hierarchical Namespace: Must be set to ENABLED (ADLS Gen2).
Container: Create a container named "synapse".
Step 03: Security & Firewall

Allow Odoo Access

Firewall Exceptions:

Azure is secure by default. You must explicitly allow the connection from Odoo to your Synapse instance.

  • In Synapse Workspace → Networking.
  • Toggle: "Allow Azure services and resources to access this workspace" to ON.
  • Click "+ Add client IP" to allow your current machine and Odoo server IP.

📷 Synapse Networking Page

Step 04: Odoo Configuration

Build Your Export Profile

Paste your Azure details into the Odoo Connector settings.

Setting up the Connector:
  • · Workspace SQL Endpoint: Your Synapse URL.
  • · Database: Your SQL Pool name.
  • · Storage Account: Your ADLS Gen2 name.
  • · SAS Token: The secret key generated in Step 2.

📷 Odoo Settings Form

Selecting Data & Domains

Choose specifically what to sync. You don't need to sync your entire Odoo database—only the valuable analytics tables.

Filter Logic Examples:

Sync only Invoices from 2024:

[('invoice_date','>=','2024-01-01')]

Sync only "Done" Stock Moves:

[('state','=','done')]
Best Practices:
  • Select only required fields to minimize IO load.
  • Test connection before running full sync.
  • Use Domain filters to exclude test data or archived records.

The Power of Incremental Sync

How we keep Azure Synapse updated without overloading your server.

1. Full Export (First Time)

On the first run, Odoo sends all records matching your filter to Azure. This establishes the baseline table.

2. Delta/Incremental Sync

Subsequent runs use a "Watermark" system. Odoo looks at the write_date and only exports rows that were modified since the last successful sync.

The "Merge" Process:

When data arrives in Synapse:

  • Matching ID Found: Synapse updates existing columns with new Odoo values.
  • New ID Found: Synapse inserts the new record.
  • Result: A perfectly mirrored table ready for Power BI.

Troubleshooting Guide

Quick fixes for common Azure connectivity issues.

Final Sanity Check:
  • SQL Pool Status: Is your Dedicated Pool "Online"? (If it's paused, Odoo can't write).
  • Networking: Is the Odoo server's IP address in the Firewall whitelist?
  • SAS Permissions: Does the SAS token include 'Write' and 'Create'?
  • SQL Credentials: Have you verified the SQL Admin password recently?

⚠ Pro Tip: Use the "Test Connection" button in Odoo before running a 1,000,000 row export. It validates storage and SQL access in 2 seconds.

Synapse Connector FAQ

Does it work with Serverless Pools?

Currently, our connector is optimized for **Dedicated SQL Pools** to ensure consistent performance for Power BI.

What version of Odoo?

Full support for Odoo Community, Enterprise, and Odoo.sh (Versions 16, 17, and 18).

Is there a row limit?

No. Azure Synapse is built for Petabyte-scale data. Your only limit is the Odoo server's processing memory for large batches.

Can I sync binary files?

We focus on structured data (text, numbers, dates). Attachments are generally handled via direct ADLS links rather than SQL pools.

Does it support Power BI?

Yes! Synapse is Power BI's best friend. Once data is in the SQL pool, just use the native Azure Synapse connector in Power BI Desktop.

Is my data safe?

100%. The data never leaves your infrastructure. It moves from Odoo to **your** Azure account directly.
